# Эксперимент последовательных заданий

Ветка `codex/task-progression` основана на инструментах дизайнера, но не объединена с основной `codex/designer-tools`. Открывайте `project.godot` именно из этой ветки. Стартовая сцена уже включает режим заданий.

## Правила прототипа

Одновременно есть три слота. Уровень содержит пять подготовленных запросов в случайном порядке без повторов. Сданные ресурсы списываются со склада с сохранением резервов пищи. Запрос даёт 25 секунд и один «Знак колонии». Кнопка показывает время и редкую награду; подсказка перечисляет полную награду и стоимость. При исчерпании пула оставшиеся слоты закрываются до перехода уровня.

Отказ по умолчанию стоит треть текущего запроса, округлённую вверх по каждому виду ресурса. Он не даёт времени и награды, но учитывается в пяти закрытых заданиях. В TaskSpec можно вместо доли задать Cancellation Costs, включая особый ресурс. Нулевая доля тоже допустима, если это намеренно задано дизайнером.

После первого уровня открывается быстрая тропинка со стоимостью прохода 0.2 вместо 0.35. После второго — скидка 10% на строительство. После третьего — ускорение муравьёв на 15%. Скорость применяется и к существующим, и к новым жителям; идущие на работу переоценивают назначения. Меняется цвет муравейников. Это пока цветовой маркер уровня, не новый набор анимаций.

За три знака можно поставить новую столовую. Знаки не производятся обычными предприятиями. Дополнительная столовая реально участвует в поиске пищи и проверках безопасности.

Третий набор повторяется с ростом цен в 1.25 раза за каждый последующий уровень и повторным улучшением скорости. Режим по умолчанию продолжается до исчерпания времени; фиксированной победы за склад 100/100/100 здесь нет. Для конечной последовательности выключите Loop Last Stage в TaskDeck: закрытие последнего уровня завершит партию победой. Итоговый экран показывает достигнутый уровень, выполненные запросы и отказы.

## Данные

`game/tasks/default_deck.tres` содержит три набора по пять запросов. TaskSpec задаёт цену, время, ресурсы награды и необязательную отдельную цену отказа. TaskStage задаёт запросы и улучшение. TaskDeck задаёт уровни, долю отказа, повтор последнего набора, коэффициент сложности и открываемую дорогу. Всё редактируется стандартным Inspector.

Ресурс редкой валюты — `game/resources/dot_treses/royal.tres`. Цены столовой и дороги находятся в каталоге построек. Базовые цены не мутируют: скидка и правила цены вычисляются при выдаче котировки. Новая карта не генерируется: в прежнем TileSet добавлен альтернативный вариант дорожного тайла, исходные клетки сохранены.

Сборка без TaskDeck продолжает поддерживать прежние фиксированные цели. Основные доменные регрессии используют именно эту явную фикстуру; новый директор заданий проверяется отдельно. Старый визуальный раннер также явно включает фиксированную цель; новый `tests/task_visual.tscn` проверяет настоящий режим заданий.

## Проверки и ограничения

`tools/check.sh` проверяет три предложения без повторов, оплату, отказ без наград, переходы уровней, открытие дороги, скидку, ускорение и запрет сдачи после поражения. `tools/check_tasks_ui.sh` проверяет действия мышью, реальную стройку дороги и столовой, масштаб, совместимость с режимом маршрутов и итоговый экран.

Для быстрой проверки нескольких уровней визуальный сценарий временно пополняет склад; для окна поражения явно исчерпывает таймер. Эти вмешательства относятся только к тесту и не меняют стартовые конфиги. Записи в `evidence/tasks/` являются проверками интерфейса, не доказательством баланса.

Числа запроса, 25 секунд, треть цены отказа и награды — исходные параметры для плейтеста. Интересность цикла и итоговая сложность ещё требуют игры человеком. Сохранения между партиями, ветвящиеся условия наград и выбор улучшения игроком не добавлены.

# Составная стоимость построек

Откройте определение в `game/building/options/`. Поле **Costs** — массив `ResourceAmount`. Для цены «5 камня и 20 пищи» добавьте два элемента: `type = stone.tres, amount = 5` и `type = food.tres, amount = 20`. Скрипты менять не нужно.

Пустой массив означает бесплатную постройку. Повторные элементы одного ресурса суммируются при проверке. Некорректный элемент запрещает покупку. Все встроенные определения перенесены с прежнего поля `cost` в `costs` без изменения цен. Свои старые определения нужно перенести аналогично.

Склад проверяет всю цену до списания. Если чего-то не хватает, все остальные ресурсы остаются нетронутыми. Зарезервированную муравьями еду потратить нельзя. Муравейник дополнительно должен оставить порции для новых жителей после оплаты собственной цены.

Меню показывает количество и название каждого ресурса. Рестарт матча доступен через «Заново» в меню паузы; он создаёт новый мир, сбрасывает таймер и сохраняет настройки.

Карта по умолчанию уменьшена до 50×50; плотное навигационное поле занимает 12 500 байт вместо 50 000 на 100×100. Камера учитывает действительные границы карты.

Масштаб UI меняется в настройках: 50%, 75% или 100%. Исходное значение — 75%. Размеры панелей изменяются сразу и сохраняются. Шрифты переключаются между исходными пиксельными сетками Pixuf 8 px и BoldPixels 16/32 px; промежуточные кегли не используются. После обновления игры нужен новый запуск F5, чтобы пересоздать уже существующие Label.

# Проверка экспериментальных заданий

Доменный раннер прошёл 597 проверок и проверку стартового дома. `domain-report.json` содержит метрики и ревизию соответствующего исходного кода. Валидатор сохранённого `wolrd_1.tscn` вернул `LEVEL VALIDATION PASS`.

Отдельные GUI-прогоны в 1280×720 и 960×600 прошли по 80 проверок: проверяют три карточки, оплату, отказ без награды, переходы уровней, реальные дорожный тайл и столовую, скидку, ускорение, масштаб 100%, режим маршрутов и экран истечения времени. Скриншоты и отчёты лежат в каталогах разрешений. Запись `tasks.mp4` воспроизводится с обычной скоростью 30 кадров/с и содержит только изображение игры и её Dummy-аудиодорожку; микрофон и рабочий стол не захватывались.

Визуальная фикстура временно пополняет запасы для проверки нескольких уровней и явно исчерпывает таймер для итогового экрана. Это демонстрация интерфейса, не естественная партия и не доказательство баланса. Реальный стартовый конфиг не меняется. Масштабирование с целым коэффициентом создаёт поля вокруг игрового изображения при 960×600.

В ходе свежего импорта установленный Godot 4.7.2 упал в C++ при обработке BoldPixels.ttf до запуска игры. Независимый повтор прошёл. Ошибка движка остаётся открытой. Выявленные ошибки пересоздания кнопок и перекрытия подсказок исправлены и покрыты отдельными визуальными проверками.

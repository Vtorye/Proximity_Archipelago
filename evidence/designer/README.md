# Проверка инструментов дизайнера

Доменные проверки и проверка исходного дома прошли: см. domain-report.json. Старый GUI-раннер прошёл 160 проверок; отдельный раннер проверяет две числовые карты, составную цену дома, обновление открытого меню после сохранения .tres и скорость эталонного муравья. Все четыре основных кадра просмотрены, дизайнерский сценарий записан в designer.mp4.

Основная карта содержит те же 2500 клеток. До изменения цены дома симуляция с дорогами воспроизводила прежние 140.02 с; с новой ценой 10 дерева + 20 камня победа наступает за 125.02 с. Бездействующая колония по-прежнему проигрывает на 180-й секунде. Голодных смертей в этих сценариях нет. Карта, слоты и стоимость перемещения сохранены.

Запись изменения цены редактирует файл только в изолированной копии и восстанавливает его. Это не изменение опубликованного баланса. Встроенное правило house_growth.tres доступно для подключения дизайнером; по умолчанию дом имеет фиксированную составную цену.

Во время отдельного импорта экспериментальной ветки установленный Godot 4.7.2 один раз упал в C++ до начала игрового теста. Независимый повтор импорта прошёл. Ошибка движка не объявляется исправленной.

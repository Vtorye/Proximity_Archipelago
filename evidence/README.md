# Материалы проверки

`before/` — пять исходных снимков и видео прежнего интерфейса. `after/` — 43 актуальных снимка, два видео и отчёты GUI. Необработанные AVI исключены из Git.

- `after/interface-walkthrough.mp4` — 39,13 с, 1280×720, H.264 и AAC. Все основные меню и игровые действия проходят через события GUI.
- `after/display-settings.mp4` — 3,8 с. Реальный fullscreen 1920×1080 и возврат в окно 1280×720.
- `after/ui-report-1280.json` — 122 проверки основного сценария.
- `after/ui-report-960x600.json` — 12 проверок компактного окна с целым масштабом и полями.
- `after/ui-report-1920x1080.json` — 12 проверок отдельного viewport с увеличением 3×.
- `after/display-report.json` — проверка реального режима окна.
- `domain-report.json` — 461 проверка логики, профили навигации и две симуляции матча.
- `media-report.json` — количество кадров, проверки и характеристики видео.

Итого: 461 проверка логики, 146 проверок GUI и отдельный сценарий fullscreen; провалов нет. Чистый импорт и существующий house_test также проходят. Числа проверок не означают такое же количество независимых функций.

Снимки 01–05 и 26 показывают главное меню/настройки; 06–12 — матч, выделение, подсказки, края и масштаб; 12a–17 — все варианты стройки, снос и столовую; 18–23 — паузу, вложенные настройки, сетку, камеру и воду; 24–25 — результаты матча; 27–28 — режимы окна. `layout-*` показывает дополнительные размеры.

UI-сценарий принудительно создаёт условия победы и поражения для проверки соответствующих окон. Реальный баланс проверяется отдельно: без действий поражение через 180 с; с построенной сетью дорог победа примерно через 158 с. В обеих симуляциях нет голодных смертей.

Все 43 итоговых снимка просмотрены; видео проверены по извлечённым кадрам, длительности, потокам и читаемости. По результатам просмотра исправлены перекрытия меню/подсказок/целей, размер шрифта, прозрачность панелей и слияние муравьёв при выходе из дома. Исходная ревизия указана в каждом отчёте; последующие коммиты материалов не меняют игровую логику.

Воспроизведение: `./tools/check.sh` и `./tools/check_ui.sh` из корня проекта. GUI требует X11, OpenGL и ffmpeg. Все проверки выполняются в временных копиях с отдельными пользовательскими настройками.

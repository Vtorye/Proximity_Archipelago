# Проверки общей ветки fix/dan

Эта ветка содержит составную цену, рестарт, центрирование точек, карту 50×50, уменьшенный UI и настройку масштаба. Экспериментальная нижняя палитра сюда не входит; она находится в ui/dan.

`domain-report.json`: 528 проверок без ошибок; house_test также пройден. Последующие изменения относятся к UI. `ui-report.json`: 160 проверок полного интерфейса и нативных размеров шрифтов, исходная ревизия b637860. `interface.mp4` содержит запись прохода через реальный GUI. Выбранные PNG показывают настройки, HUD, строительство, паузу и рестарт. Кадры просмотрены визуально.

Масштаб по умолчанию 75%, доступны 50–100%. Для мелкого текста используется Pixuf 8 px, для крупного — BoldPixels 16/32 px. На 50×50 стартовые здания находятся внутри карты; навигационное поле занимает 12 500 байт. Инертная стратегия проигрывает за 180 с; дороги и дополнительный дом позволяют выиграть примерно за 140 с. Голодных смертей нет в обоих сценариях.

Проверка выполнена в Godot 4.7.2 на Linux/X11/OpenGL. Это не проверка Windows WASAPI. Исходные пользовательские изменения project.godot не включены в коммиты.

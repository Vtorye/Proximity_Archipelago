# Проверка объединённой fix/dan

Коммит слияния: `5dcbea3`, родители `e6de6a9` (fix/dan) и `2a114fc` (dan/ui). Слияние выполнено без конфликтов; дерево файлов совпадало с проверенной dan/ui.

После слияния чистая копия репозитория прошла 573 доменные проверки и `house_test`. `domain-report.json` содержит результаты и исходную ревизию. Все игровые цены, производство и условия питания сохранены.

Нативный сценарий настроек прошёл переключение fullscreen и возврат в оконный режим без ошибок. Сохранены два PNG, `display-report.json` и `display-settings.mp4` (114 кадров).

До слияния тот же игровой код прошёл 312 проверок нового UI на 1280×720, 312 на 960×600 и 160 проверок общей регрессии. Эти отчёты, 50 основных/компактных снимков и два видео находятся в `../construction/`. Снимки и покадровый обзор основного видео просмотрены.

Проверено на Linux с Godot 4.7.2. Незакоммиченные изменения пользователя в project.godot сохранены отдельно и в слияние не вошли. Ветки main и mechanical_change не менялись.
